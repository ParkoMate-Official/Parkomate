# UI Rebuild Visual Comparison: Before (Baseline) vs After (Olive Rebuild)

This document provides a comprehensive side-by-side comparison of the 26 application states across both English (`en`) and Marathi (`mr`) locales (52 screenshots total).

**Baseline Directory**: `docs/ui_rebuild/baseline-run/`  
**After Directory**: `docs/ui_rebuild/after/`  
**Tracked Screenshots**: `docs/screenshots/`  
**Resolution**: 1366 × 768 px

---

## Summary of Global Design Changes

1. **Brand Identity Transition**: Replaced legacy default blue (`#1849A9` / `#1D4ED8`) with factory-approved **Olive** (`#5A6F2D`) for all interactive elements (primary buttons, active tabs, current stepper capsule) and **Yellow** (`#B59E2B` / `#FACB34`) for decorative progress chunks, alerts, and mode banners.
2. **Card Geometry & Hierarchy**: Upgraded cards from tight 8 px borders to generous 16–24 px rounded containers (`#FFFFFF`) with 1 px borders (`#DDE3CB`). Modal dialogs and Login cards use 24 px radius.
3. **Four-Sided Tone Borders**: Eliminated heavy 1-sided colored left accent stripes on step cards in favor of a clean, balanced **2 px four-sided tone border** (`card[tone="..."]`).
4. **Nested Tint Panels**: Grouped secondary telemetry and metadata inside rounded `#F1F4E8` (soft olive tint) containers within cards.
5. **Bench Ergonomics**: Primary action buttons are strictly ≥ 56 px tall; input fields and combo boxes are ≥ 48 px tall; body typography standardized at 18 px base with high-contrast `#111111` for primary text.
6. **Hero Telemetry Numbers**: Primary sensor measurements, temperatures, and batch counts display in prominent 28–36 px bold typography for effortless at-a-glance visibility from standing bench positions.
7. **Bilingual Typography & Script Protection**: Uppercase tracked typography (`letter-spacing: 1.5px`) is applied to English headers and category tags, but strictly disabled (`letter-spacing: 0px`, no case transforms) in Marathi to preserve Devanagari headline (*shirorekha*) continuity and prevent clipping.
8. **Double-Ring Focus Accessibility**: Interactive inputs and buttons use an accessible high-contrast double-ring focus indicator (`#111111` outline with a 2 px offset).
9. **Zero Inline Styles**: All dynamic UI styling flows through QSS rules and Qt dynamic properties (`tone`, `variant`, `box_letter="true"`).
